# Set A·Set B 분포 차이 대응 및 변수 선정 전략

> 기준 데이터: PhysioNet/CinC Challenge 2019 공개 학습 데이터 40,336명, 1,552,210시간 행  
> 분석일: 2026-09-22, 의사결정 개정: 2026-09-27  
> 재현 명령: `python scripts/compare_setab_distributions.py`, `python scripts/compare_sepsis_vs_nonsepsis.py`  
> 수치 원본: `docs/setA-setB-variable-distribution.json`, `docs/setA-setB-sepsis-vs-nonsepsis-distribution.json`, `docs/physionet-actual-profile.json`

## 1. 결론

1. **Set A와 Set B에서 선정한 동일 컬럼만 추출한 뒤 함께 학습한다.** 원본 40개 입력 컬럼을 무조건 모두 합치는 것이 아니라, 아래에서 근거를 확인한 16개 임상 변수와 시간·결측 파생 특징만 사용한다.
2. 병합은 환자의 행을 이어 붙이는 방식(concatenation)이다. A의 값으로 B의 값을 덮거나 두 병원의 같은 시각을 평균내지 않는다. `hospital_set`을 보존하고, A/B 각각에서 환자 단위로 train/validation/test를 먼저 나눈 뒤 같은 split끼리 합친다.
3. 최종 입력은 선정된 16개 임상 변수와 각 변수의 **관측 여부, 마지막 관측 후 경과시간, 최근 24시간 측정 횟수**를 사용한다. 결측 자체가 검사 주문과 병원 업무 흐름을 반영하기 때문이다.
4. 병원 간 차이가 큰 `MAP`, `DBP`, `SBP`, `Temp`, `WBC` 및 결측률 차이가 큰 `DBP`, `Resp`, `Bilirubin_total`, `FiO2`, `Glucose`, `pH`도 임상적 필요성이 있으면 제거하지 않는다. 병합 train으로 전처리기를 적합하고, 병원별 성능과 결측 패턴별 성능을 따로 확인한다.
5. 패혈증 구분 근거가 두 병원에서 비교적 일관된 변수는 `HR`, `Resp`, `BUN`, `Temp`, `WBC`, `Creatinine`이다. 특히 기존 목록에 있던 **BUN은 유지 근거가 강하다**.
6. 표준 SOFA와 qSOFA 점수를 완전하게 계산할 수 없다. `GCS`, `PaO2`, 승압제 용량, 소변량이 없다. 따라서 **Partial SOFA/qSOFA 구성요소를 원본 특징으로 사용**하며 완전한 점수처럼 부르지 않는다.
7. 클래스 불균형은 환자 균등 샘플링과 weighted loss를 비교한다. 최종 선택 기준은 병합 validation 성능뿐 아니라 **Set A와 Set B 각각의 AUPRC·Utility·Brier와 calibration**이다.
8. 이 설계에서 Set B는 외부 검증 세트가 아니다. A/B 모두 학습에 참여하는 **다기관 학습·내부평가**이며, 외부 검증에는 모델 개발에 전혀 쓰지 않은 제3 병원 또는 시간적으로 분리된 데이터가 필요하다.

## 4. 실제 분포·측정빈도·결측 비교

아래 중앙값은 환자별 관측값 평균의 중앙값이다. 따라서 체류 시간이 긴 환자가 결과를 독점하지 않는다. `시간 관측률`은 전체 시간 행 중 값이 있는 비율이고, `환자 측정률`은 입실 중 한 번이라도 측정된 환자 비율이다. 결측률은 `100 - 시간 관측률`이다.

## 6. SOFA·qSOFA 사용 원칙

### SOFA

사용 가능한 구성요소는 `Platelets`, `Bilirubin_total`, `Creatinine`, `MAP`이다. 호흡은 `PaO2/FiO2`가 필요한데 `PaO2`가 없고, 중추신경계 `GCS`, 신장 소변량, 심혈관 승압제 용량도 없다.

- 표준 SOFA 총점을 계산하지 않는다.
- `O2Sat`와 `FiO2`를 `PaO2/FiO2`의 등가물로 치환하지 않는다.
- 위 변수 및 결측 특징을 개별 입력으로 사용한다.
- 별도 파생점수를 만들면 이름은 `PartialSOFA_features`로 하고 표준 SOFA와 구분한다.

### qSOFA

사용 가능한 것은 `SBP`, `Resp`뿐이고 `GCS`가 없다.

- `SBP ≤ 100`, `Resp ≥ 22` 두 항목을 각각 이진 특징으로 둘 수 있다.
- 합계는 0~2의 `Partial qSOFA`로만 표기한다.
- 두 변수의 연속값도 함께 유지한다. 임계값만 쓰면 정보가 손실된다.

## 7. 선정 컬럼 기반 병합 및 분포 차이 대응 전략

### 7.1 기본 병합 절차

1. A/B 모두에서 환자 ID와 `hospital_set`을 부여한다.
2. 두 병원에서 동일하게 존재하는 선정 16개 컬럼만 추출한다. `SepsisLabel`은 target으로만 분리한다.
3. **A/B 각각** 환자 단위로 train/validation/test를 나눈다. 권장 비율은 70/15/15이며, 각 병원 안에서 패혈증 환자 비율을 층화한다.
4. A-train과 B-train, A-validation과 B-validation, A-test와 B-test를 각각 합친다. 같은 환자의 시간 행은 하나의 split에만 존재해야 한다.
5. 결측 대치값, clipping 경계, scaling 파라미터는 **병합 train에만 적합**하고 validation/test에는 그대로 적용한다.
6. 변수마다 `value`, `observed`, `time_since_last`, `count_24h`를 만든다. 미래 관측값으로 과거 결측을 채우지 않는다.
7. 전체 성능과 A/B 병원별 AUPRC, AUROC, Utility, Brier, calibration을 모두 보고한다.

병합의 목적은 두 병원의 환자 특성과 측정 관행을 모델이 함께 학습하게 하는 것이다. 단, 전체 평균 성능이 좋아도 한 병원에서 성능이 크게 낮으면 채택하지 않는다.

### 7.2 결측률이 높은 필수 변수 처리

결측률만으로 변수를 삭제하지 않는다. 아래 세 조건 중 하나를 만족하면 유지한다.

- SOFA/qSOFA 등 임상적으로 중요한 장기기능 구성요소다.
- 두 병원 중 적어도 한 병원에서 충분히 관측되고 실제 배포 환경에서도 획득 가능하다.
- 값 자체 또는 검사 시행 여부가 패혈증 위험과 관련될 합리적 근거가 있다.

이에 따라 `Lactate`, `Bilirubin_total`, `FiO2`, `pH`는 높은 시간 결측률에도 유지한다. 처리 원칙은 다음과 같다.

- 관측값이 있으면 실제 값을 사용한다.
- 결측값은 병합 train에서 산출한 robust statistic(기본: 중앙값)으로 대치하되 `observed=0`을 함께 넣어 “실제 정상값”과 구분한다.
- 이전 관측값 전달은 현재 시점 이전 값에만 적용하며 `time_since_last`를 함께 넣는다.
- 한 번도 측정하지 않은 환자를 제거하지 않는다.
- 특정 검사가 없는 행을 음성 또는 정상으로 간주하지 않는다.
- 결측이 지나치게 많은 변수는 전체 모델과 해당 변수 제외 ablation을 비교하되, **결측률만을 이유로 자동 제외하지 않는다.**

### 7.3 샘플 가중치

환자 양성률 기준 balanced loss의 출발값은 다음과 같다.

- Set A: 양성 `20,336 / (2 × 1,790) = 5.68`, 음성 `20,336 / (2 × 18,546) = 0.55`
- Set B: 양성 `20,000 / (2 × 1,142) = 8.76`, 음성 `20,000 / (2 × 18,858) = 0.53`
- A+B 병합: 양성 `40,336 / (2 × 2,932) = 6.88`, 음성 `40,336 / (2 × 37,404) = 0.54`

그러나 한 환자에게 여러 시간 행이 있으므로 행 단위 역빈도 가중치를 그대로 적용하면 긴 입원과 발생 후 양성 행이 과대표집된다. 권장 순서는 다음과 같다.

1. mini-batch에서 환자를 균등 추출한다.
2. 환자 안에서 시간창을 추출하되 발생 전/발생 근처/음성 창의 비율을 통제한다.
3. 무가중 loss, 병합 class-balanced loss, `병원 × 라벨` 4개 층 균형 loss를 비교한다.
4. 극단 가중치가 calibration을 악화하면 양성 가중치를 validation에서 조정하거나 focal loss가 아니라 더 단순한 capped weight를 우선한다.
5. 평가 세트에는 가중치를 적용하지 않고 실제 prevalence 그대로 평가한다.

### 7.4 도메인 적응을 고려하는 조건

다음 중 하나가 확인될 때만 도메인 적응 실험으로 넘어간다.

- A와 B 중 낮은 병원의 AUPRC 또는 Utility가 높은 병원 대비 20% 이상 상대 하락
- A와 B 중 한 병원의 Brier score가 다른 병원 대비 20% 이상 상대 악화
- calibration slope가 0.8 미만 또는 1.2 초과
- 핵심 변수의 결측 패턴별 성능 격차가 임상적으로 큼

실험 우선순위:

1. **병원별 확률 재보정:** validation에서 병원별 Platt 또는 isotonic calibration을 비교한다. prevalence shift에 가장 직접적으로 대응한다.
2. **병원 균형 가중치:** 각 batch의 A/B 환자 수와 병원별 양성/음성 수를 먼저 균형화한다.
3. **중요도 가중치:** 단순 병원 균형으로 해결되지 않을 때 도메인 분류기로 density ratio를 추정하고 가중치를 0.2~5로 clipping한다. target과 target 이후 정보는 사용하지 않는다.
4. **CORAL 등 표현 정렬:** 중요도 가중치보다 확실히 개선될 때만 채택한다.
5. adversarial domain adaptation은 데이터·검증 복잡성이 크므로 앞선 방법이 실패한 경우에만 고려한다.

적응 채택 조건은 한 병원의 성능을 크게 훼손하지 않으면서 낮은 병원의 AUPRC·Utility·Brier 중 최소 두 지표를 사전 정의한 bootstrap 95% CI 기준으로 개선하는 것이다.

### 7.5 병합 모델 채택 조건

선정 컬럼 기반 A+B 병합을 기본 학습안으로 사용하되 다음 조건을 지킨다.

- 환자 단위, 병원 층화 분할을 사용한다.
- 각 batch의 Set A/B 환자 비율을 1:1로 맞춘다. 현재 환자 수가 20,336 대 20,000이라 단순 병원 크기 가중치는 사실상 필요 없다.
- 클래스 가중치는 병원별로 계산해 `병원 × 라벨` 네 집단 중 한 집단이 손실을 독점하지 않게 한다.
- `hospital_set`은 성능 분석과 샘플링에 반드시 보존한다. 모델 입력으로 사용할지는 별도 ablation으로 결정한다. 병원 ID에 과도하게 의존하면 새 병원 일반화가 나빠질 수 있다.
- 전처리 파라미터는 병합 train에서만 적합한다.
- 병원별 성능과 전체 성능을 모두 통과해야 한다. 전체 평균 개선만으로 채택하지 않는다.
- 결측 필수 변수 포함 모델과 제외 모델을 비교하고, 포함 모델이 병원별 성능 또는 임상적 재현율을 개선하면서 보정을 악화시키지 않을 때 유지한다.
- 제3 병원 또는 시간적으로 분리된 데이터는 완전히 잠긴 최종 외부 검증으로 남긴다.

## 8. 실험 및 채택 표

| 실험 | 학습 데이터 | 핵심 변경 | 채택 판단 |
| --- | --- | --- | --- |
| M0 | A+B | 선정 16개 변수+결측 특징, 무가중 | 병합 기준선 |
| M1 | A+B | 환자 균등 + 병합 class-balanced loss | 전체와 A/B별 AUPRC·Utility 개선, Brier 허용 범위 |
| M2 | A+B | `병원 × 라벨` 4개 층 균형 | 낮은 병원 성능 개선 여부 |
| A1 | A+B | 병원 민감 3군 제외 | `DBP`, `FiO2`의 순효과 확인 |
| A2 | A+B | 고결측 필수 변수 제외 | `Lactate`, `Bilirubin_total`, `FiO2`, `pH`의 순효과 확인 |
| A3 | A+B | 결측 파생 특징 제외 | 측정 패턴의 기여와 병원 의존성 확인 |
| C1 | A+B | 병원별 확률 재보정 | 병원별 Brier/calibration 개선 |
| D1 | A+B | importance weighting 또는 표현 정렬 | 낮은 병원에서 두 지표 이상 유의 개선 |

최종 보고서에는 전체 점수 하나가 아니라 다음을 같이 기록한다.

- Set A/Set B별 환자 수, 양성률, 시간 행 수
- 변수별 시간 결측률과 환자 미측정률
- 병원별 AUPRC, AUROC, Utility, Brier, calibration slope/intercept
- 패혈증/비패혈증 및 병원별 subgroup 결과
- 적용한 class/domain weight 공식과 clipping 범위
- 입력 변수·결측 특징 ablation 결과

## 9. 최종 의사결정

현재 데이터 근거로는 **“A/B에서 선정한 동일 16개 컬럼만 추출 → 병원·라벨을 층화해 환자 단위 분할 → 같은 split끼리 병합 학습 → 결측 패턴 특징 추가 → 전체와 병원별 평가”**를 기본 전략으로 채택한다.

결측률이 높더라도 임상적으로 필요한 `Lactate`, `Bilirubin_total`, `FiO2`, `pH`는 우선 포함한다. 다만 값이 없는 환자를 삭제하거나 결측을 정상값으로 해석하지 않고, 대치값과 관측 여부·경과시간·측정횟수를 함께 사용한다. 고결측 변수의 최종 채택은 ablation으로 확인한다.

분포 차이가 있다는 이유만으로 복잡한 도메인 적응을 바로 적용하지 않는다. 먼저 A+B 병합 기준선과 병원 균형 가중치를 평가하고, 한 병원의 성능 또는 보정이 사전 기준보다 나쁠 때만 재보정·importance weighting·표현 정렬 순서로 추가한다. Set B는 학습에 포함되므로 외부 검증으로 표현하지 않으며, 최종 외부 검증은 별도의 제3 병원 또는 시간 분리 데이터로 수행한다.
